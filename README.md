# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. Perfect for GitHub Pages deployment.

## Features

- ✨ **Responsive Design** - Works on all devices (mobile, tablet, desktop)
- 🎨 **Modern Styling** - Red and black theme with smooth animations
- 📱 **Mobile Friendly** - Optimized for small screens
- ⚡ **Fast Performance** - Pure HTML/CSS/JS, no heavy frameworks
- 🎯 **SEO Ready** - Semantic HTML structure
- 🚀 **GitHub Pages Ready** - Deploy directly from this repo

## Sections

1. **Navigation** - Sticky navbar with smooth scrolling
2. **Hero** - Eye-catching introduction section
3. **Projects** - Showcase your work with project cards
4. **Skills** - Display your technical skills and technologies
5. **Contact** - Contact form for visitors
6. **Footer** - Social links and copyright

## Getting Started

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/Tanathorn-Rin/Tanathorn-Rin.github.io.git
cd Tanathorn-Rin.github.io
```

2. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
# or
npx http-server
```

3. Visit `http://localhost:8000` in your browser

### Customization

1. **Update your information:**
   - Edit `index.html` - Change project details, skills, social links
   - Edit `styles.css` - Customize colors, fonts, layouts

2. **Change the color scheme:**
   - Find `:root` in `styles.css`
   - Modify CSS variables (e.g., `--primary-color`)

3. **Add your projects:**
   - Edit the Projects section in `index.html`
   - Update project titles, descriptions, and links

4. **Add your skills:**
   - Edit the Skills section in `index.html`
   - Add/remove skill categories and items
