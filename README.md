# Cybersecurity Portfolio - Minimal Template

A minimal, clean template for your penetration testing portfolio.

## How to Use

1. Edit `index.html` and replace placeholder text:
   - "Your Name Here" → your name
   - "Penetration Tester | Security Researcher" → your title
   - Add your about, projects, and skills

2. Colors are already set to: Red (#ff0000), Black (#000000), White (#ffffff)

3. Push to GitHub when ready

## Customization

- **HTML**: Edit sections in `index.html`
- **Styling**: Edit `styles.css` as needed
- **Colors**: Red borders and accents are built in

## Deploy to GitHub Pages

```bash
git add .
git commit -m "Your message"
git push
```

Your site: `https://yourusername.github.io`
